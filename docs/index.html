Why Cloakroom

The problem

Cloud agent browsers get bot-walled

They browse from datacenter servers with an automated browser, so big sites put up a wall. Every session starts fresh, so yesterday's login is gone.

The fix

Bring the browser home

CloakBrowser (stealth Chromium) runs headed in OrbStack on your Mac with one saved profile. Agents connect over CDP at 127.0.0.1:9222. You watch and help in the viewer at 127.0.0.1:6080.

How agents drive it

Enter like a person, not a script

Start at Bing and click the organic result. Move the mouse and type like a person. Search with the site's own box, not a hot search URL.

On September 26, 2026, a cloud Grok Bot browser was challenged or blocked on twelve big homepages (Home Depot, Ticketmaster, Sam's Club, and others). Cloakroom loaded all twelve. Homepages only; no site is guaranteed.

Real screenshots

Humanized input avoids needless challenges. When one does show up, cloakroom do works it, including press-and-hold. You can also finish it yourself in the viewer, on your Mac or on your phone with cloakroom share.

For agents

Everything an agent needs (commands, JSON output, the Bing-first entry, humanized input, 2FA, the phone viewer) is in the Cloakroom skill. Examples: bing_first.py and humanize.py.
