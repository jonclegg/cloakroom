How agents should drive it

Enter like a person, not a script.

Step 1
Enter from Bing
bing.com
AdCheap sourcing dealsads.example · skip ads
OrganicAlibaba.comwww.alibaba.com · click this
Search the site on Bing, click the organic result. Don't page.goto the target.
Step 2
Humanize input
Curved mouse moves. Click the field first. Type one key at a time with small random pauses.
Step 3
Use the site's search
# hot URL as first load: challenged
page.goto(".../trade/search?…")
# the site's own box and button
human_click(page, box)
human_type(page, "gas fireplace")
human_click(page, search_button)
Search with the site's box. Don't jump to search, listing, or product URLs.
